# Documentação da plataforma Gen

Esta documentação apresenta a plataforma por produto e descreve como seus serviços são hospedados. É o ponto de partida para compreender as responsabilidades de cada módulo e o modelo de instalação exclusiva por cliente.

1. [Visão geral dos módulos](docs/visao-geral.md) — produtos, responsabilidades, dados compartilhados e caminho de acesso.
2. [Visão de infraestrutura](docs/visao-infraestrutura.md) — serviços, Docker, publicação web e alocação de uma instalação ao registrar um cliente.

Os aplicativos estão em .NET 8 nesta etapa.
