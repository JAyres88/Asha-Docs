## Organização e manutenção

- A pasta `docs/` preserva os documentos e sua organização original.
- Novos guias, decisões de arquitetura e roadmaps devem ser mantidos neste projeto.
- O código da aplicação permanece no projeto irmão `../MainDDD/`.
- Caminhos de código citados nos documentos são relativos à raiz do MainDDD, salvo indicação contrária.
- Este projeto contém somente documentação e não exige compilação.
